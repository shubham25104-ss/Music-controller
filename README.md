# Mini Desktop Controller 🎛️

An ultra-compact, unbranded desktop media controller for Windows.

## 🎛️ Controls
- **`⏮`**: Previous track
- **`▶ / ⏸`**: Play / Pause
- **`⏭`**: Next track
- **`🔉 -`**: Volume Down
- **`🔇`**: Mute
- **`🔊 +`**: Volume Up

## 🚀 How to Run
Double-click **`MiniController.exe`** (or `Start-Controller.bat`).
